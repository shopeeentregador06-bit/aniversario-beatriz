# Site de aniversário da Beatriz ❤️

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste projeto.
3. Coloque sua música em:
   `assets/bem-chapeu-de-palha.mp3`
4. No GitHub, abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde o GitHub gerar o endereço do site.

A música não foi incluída no pacote porque é uma música comercial. Use um arquivo que você tenha direito de disponibilizar no site. O site está configurado para tentar iniciar a música automaticamente; celulares/navegadores podem bloquear autoplay com som, caso em que o primeiro toque na página inicia a música.
